# SkillUp Campus - Frontend

SPA para la plataforma educativa SkillUp Campus construida con React, Vite y Tailwind CSS.

## 🚀 Setup Local
1. Instalar dependencias: `npm install`
2. Variables de entorno: `cp .env.example .env`
3. Correr en modo desarrollo: `npm run dev`

## 📂 Arquitectura
- `src/components`: Componentes reutilizables (Navbar, Cards, Modales).
- `src/pages`: Vistas del MVP (Catálogo, Login, Dashboard de Alumno, Admin).
- `src/routes`: Sistema de enrutamiento con React Router DOM.
